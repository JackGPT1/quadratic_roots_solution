
# Quadratic Roots Solver

A Python implementation of the quadratic formula for solving quadratic equations.

## Overview

This project implements a Python function to calculate the roots of a quadratic equation:

\[
ax^2 + bx + c = 0
\]

## Features

- Calculates two distinct real roots.
- Handles identical real roots.
- Handles complex roots.
- Checks whether the coefficient `a` is non-zero.

## Requirements

- Python 3
- math module (built-in)

## Usage

```python
import math

root1, root2 = quadratic_roots(1, -3, 2)

print(root1, root2)
```
